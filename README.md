# Artificial Intelligence in Augmented Reality Applications

Augmented Reality Sandbox. open-AR-Sandbox is a project to enable haptic interaction with geoscientific content in AR-Sandboxes. Varjo OpenXR plugin. UniversalRAG Retrieval-Augmented Generation over Corpora of Diverse Modalities and Granularities. VINS-Mobile is a real-time monocular visual-inertial state estimator. Micropython ported to the Monocle. TensorFlow Lite for Microcontrollers. OCAML-NN is a fully functional monadic implementation of a Fully-Connected Neural Network (FCNNs). Kornia is a differentiable computer vision library. SOD is a modern cross-platform machine learning software library. SolARFramework is an open-source framework making possible to easily create your own camera pose estimation solution to develop Augmented Reality applications. Pytorch Implementation of Deepmind's SIMA. The NVIDIA Data Loading Library (DALI). Maid is a cross-platform Flutter app for interfacing with GGUF / llama.cpp models locally, and with Ollama and OpenAI models remotely. XR-Objects is an open-source prototype that anchors contextual interactions onto analog objects to not only convey information but also to initiate digital actions, such as querying LLMs for details or executing tasks. Creating an early form of Augmented Object Intelligence. The DeepReality Unity package is aimed at simplifying and streamlining the usage of machine learning models in conjunction with the AR functionality. VIAME is a computer vision application. The Compute Library is a collection of low-level machine learning functions. Google’s ARCore use AI to enhance facial tracking, improving AR filters and immersive experiences. OpenARK is an open-source wearable augmented reality (AR) system. OpenCV Mobile is a minimalist build of the popular OpenCV library, specifically optimized for mobile and embedded platforms. The nRF52 is designed to handle the overall system operation. OpenTabletDriver is an open source cross platform, user mode tablet driver. Gzweb is a WebGL client for Gazebo Classic

The directory structure includes a specific folder for each phase of development and engineering programs:

- __MBSE__: The root folder Arcadia (ARChitecture Analysis and Design Integrated Approach) is a method of tools dedicated to systems engineering and architecture, supported by the Capella modeling tool.    
  - __CAD__: For computer-aided design.
  - __CAM__: Dedicated to the part manufacturing and assembly process.
  - __CAS__: For simulation of end-to-end functionality and performance analysis.
